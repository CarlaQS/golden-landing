# GOLDEN &mdash; Plataforma E-commerce y Sistema de Gestión Integral

Landing page profesional y responsive para el proyecto **GOLDEN**: Solución tecnológica B2B/B2C orientada a la distribución especializada de aceites y filtros automotrices en **Sucre, Bolivia**.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura limpia y optimizada para SEO y accesibilidad.
- **CSS3 Moderno**: Variables personalizadas, Flexbox, CSS Grid, animaciones suaves y diseño responsive adaptativo (*mobile-first*).
- **JavaScript Puro (Vanilla JS)**: Menú interactivo, navegación suave, scroll-spy dinámico y retroalimentación de formulario.
- **Sin Dependencias Externas Pesadas**: Iconografía SVG en línea y Google Fonts de alto rendimiento.

---

## 🎨 Especificaciones de Diseño

- **Fondo Oscuro:** `#121212` (estética automotriz moderna y técnica).
- **Color de Acento:** Dorado `#e8a817` con estados hover y reflejos de iluminación.
- **Tipografía:** *Plus Jakarta Sans* y *Space Grotesk*.
- **Arquitectura Visual:** Tarjetas con bordes suaves, navegación fija (*glassmorphism*) y compatibilidad total en dispositivos móviles.

## 🚀 Despliegue en Render (Static Site)

Esta landing page está lista para ser desplegada como **Static Site** gratuito en **Render**:

1. Sube este repositorio a **GitHub**.
2. Ingresa a tu panel de control en [Render.com](https://render.com/).
3. Haz clic en **New +** y selecciona **Static Site**.
4. Conecta tu repositorio de GitHub `golden-landing`.
5. Configura los parámetros:
   - **Name**: `golden-landing` (o el nombre de tu preferencia)
   - **Branch**: `main` (o `master`)
   - **Build Command**: *(Dejar en blanco)*
   - **Publish Directory**: `.` (o `./`)
6. Presiona **Create Static Site**. ¡En pocos segundos estará público con certificado SSL gratuito!
